# Vite Task

Build, test, lint and format commands, as defined in `justfile`:

- Type-check the workspace: `just check`
- Run the tests: `just test`
- Run clippy with warnings denied: `just lint`
- Format Rust and other files: `just fmt`
- Build the docs with warnings denied: `just doc`
- Run the full local check sequence before pushing: `just ready`

# store_package_node_modules_with_only_bin_counts_as_missing

pnpm creates `<pkg>/node_modules/.bin` inside its store only while it runs that package's build script, so a cold store has the directory and a warm store does not. Module resolution checks the directory on its way up. One that holds nothing but `.bin` is fingerprinted as missing, so both installs match; one with another entry is a real input.
